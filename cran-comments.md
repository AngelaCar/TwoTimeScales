# Submission of TwoTimeScales v 1.3.0

This is a new minor version (1.3.0) of TwoTimeScales, previously accepted as 1.2.1. 
In this version two new functions are added:

* A wrapper function that performs non-parametric bootstrap to obtain uncertainty
  estimates of the cumulative incidence functions and the overall survival function
  with two time scales
  
* A function to plot these estimates.

The major changes are documented in the NEWS file.
